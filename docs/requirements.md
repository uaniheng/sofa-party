# 沙发派对 — 需求说明

> 版本：v0.20  
> 日期：2026-09-21

---

## 这是什么

在家里的 **Wi‑Fi** 上，在一台 **电脑** 上打开 **沙发派对**（以后也可以装到电视上，但不是必须）。这台电脑就是 **主机**。

电视、手机、平板用自带的 **浏览器** 分别去访问这台电脑的地址，就能一起玩游戏。

不用每人去应用商店下 App，不用注册账号，也不用连外网才能玩。

像 **Switch 马里奥派对的小游戏**：大家先聚在一个大厅里，选一款小游戏，所有在场的人一起玩；玩完回到大厅，再换下一款。

家里 **同时只玩这一款**，没有「房间号」，也不会分成两桌。

---

## 一个晚上怎么玩

1. 在家里电脑上启动主机。电脑上用**很大的字**显示大屏地址，另外一张二维码是给手机的。  
2. **电视一般不能扫码**（没有摄像头）。用电视自带浏览器，把电脑上那串大屏地址敲进去；或把电脑 HDMI 接到电视上，点「本机当大屏」。  
3. 大家用手机扫「给手机的」码。第一次来：创建一个名字，比如「小明」。以后换手机，还选「小明」就行。  
4. 大厅里能看到：电视是否已连上、谁已经进来了、有哪些游戏。  
5. 随便谁（用手机）点一款游戏，大家一起开始。  
6. 玩完自动回大厅，再选下一款。

没有电视时：可以在电脑上点「本机当大屏」，用电脑显示器凑合玩。

---

## 两种玩游戏的方式

不同游戏，屏幕用法不一样。框架两种都支持。

### 方式一：每人看自己的屏幕

适合：答题、有卧底/身份、不想让旁边的人看见自己的牌。

- 每个人的手机上就是游戏画面，自己点自己的。  
- 电视可以开着当公共大厅，也可以不开。

### 方式二：一块大屏，手机当手柄

适合：赛车、派对小游戏、所有人盯着同一块屏幕看的游戏。

- **画面只出现在大屏上。** 打开大屏地址的那台设备就是这块屏幕，可以是电视、手机、平板或电脑。  
- 选了角色的手机打开后 **只有方向键、按钮**，像遥控器，不把整场比赛画在手机上。  
- 很像 Switch 插电视：一块屏幕，几只手柄。屏幕是连接角色，不是某一种设备。

> 以后还可以做第三种：电视上看公共画面，手机上另有「只有自己能看的信息」（类似有的派对游戏）。先记着，不必第一版就做。

选哪一种，由 **这款游戏自己声明**，玩家不用配置。

---

## 游戏规则在哪儿算

大屏是一个连接角色，不是一台特定的电视。手机、平板、电脑，只要打开大屏地址，就是这块给大家看的画面。它不选名字，不算玩家，也不算规则。

规则只在两个地方算：

1. **某个玩家当计算端。** 游戏没带主机脚本时，由点开始的那位玩家的页面来算，再把画面发给大屏，把结果发给其他人。每人一屏、大屏+手柄都是这样。  
2. **主机里的小游戏服务。** 游戏如果带了 `server.js`，规则就在沙发派对进程的工作线程里算。大屏只画，玩家只发操作。适合不能让某一台手机改分数的玩法。

主机不会在游戏没要求时自己算规则。没带脚本时，它只做人名、存档、传话、装游戏。

主机里的这份脚本权限很小：不能乱访问电脑文件夹、不能自己再开一套服务。它崩了只结束这一局，不会把整个主机带挂。

---

## 主机负责什么

| 主机做 | 主机不做 |
|--------|----------|
| 给家里一个网址，让浏览器能打开 | 不当成网游平台，不连外网对战 |
| 记住家里每个人的名字和编号 | 不搞账号密码（除非以后你要求） |
| 告诉游戏：现在在线的是谁 | 不拆成多个房间 |
| 帮游戏存进度（存在这台主机上） | 不把进度同步到云 |
| 把手机的按键转给游戏，把画面状态转给电视 | 不审核、不收费上架 |
| 安装游戏：拷文件夹，或从网上的「游戏源」下载 | 不要求家人再装数据库、Node 这些软件 |

家人拿到的是 **一个可执行文件**，双击就能开。开发的人自己电脑上才需要安装开发工具。

---

## 家里的「人」怎么认

每个人在主机上有一份 **档案**：名字 + 系统给的固定编号 + 一种颜色。

- 游戏用这个编号区分「爸爸」和「小明」，而不是用哪台手机。  
- 换手机再点自己的名字，**前提是这个人现在没人占用**。已经有人进来了，别人不能再选。  
- 电视这块大屏 **不算一个玩家**，不用选名字。  
- 选人是「抢」：谁先点到谁就是；选人页要实时看到谁已经被选走。同一人刷新自己的页面可以接着玩，但不能把别人已经选走的名字再抢过来。  
- 建议：家里最多十几个档案，同时玩不超过 8 人。

---

## 进度怎么存

游戏如果要存关卡、分数、图鉴，应交给主机，不要只存在某台手机里（换手机就没了）。

两种存法：

- **只属于某一个人**（我的关卡）  
- **全家共用一份**（客厅总奖杯）

内容主机看不懂，只负责代为保存。卸掉游戏后，进度默认还留着，重装同款还能接着玩。

---

## 游戏从哪来

大厅只列出 **已经装到这台主机上的游戏**。

装法有两种：

1. 把游戏文件夹放进主机的游戏目录，点刷新。  
2. 在主机上添加一个 **游戏源**（别人公开的一份游戏目录网址），浏览后下载。下载发生在主机上；下完以后，即使主机断了外网，家里仍能玩。

下载的是打包好的压缩包，要核对校验码，防止下到被改过的文件。  
框架自己 **不办应用商店、不审核**。你添加某个源，就表示你信任那个源。

建议：下载、加源只在「主机管理」里做，避免小孩用电视乱装。

---

## 家里设备怎么摆（默认）

**主机装在电脑上。电视和手机都只是来访问的浏览器，不必再装一份主机。**

```
家里电脑  ──运行主机程序──  存游戏、存名字、传话
     │
     ├── 电视浏览器   打开「大屏地址」   → 客厅屏幕
     ├── 手机浏览器   打开「加入地址」   → 选名字 / 当手柄
     └── 平板等同手机
```

- 电脑负责跑服务，可以关着显示器，不必一直看着电脑。  
- 电视不装主机，只要能打开网页。**二维码是给手机的，不是给电视的。**  
- 电视怎么打开大屏，见下一节。

也可以这样变通（都支持，不是默认）：

| 摆法 | 什么时候用 |
|------|------------|
| 电脑当主机 + 电脑自己当大屏 + 手机当手柄 | 没电视，或开发调试 |
| 主机直接装在电视上，电视自动进大屏，手机来加入 | 以后做电视安装包；第一版不做 |

注意：只打开网页，当不了主机。必须有一台设备 **运行主机程序**（默认就是那台电脑）。

---

## 电视怎么连上（不能扫码）

客厅电视几乎都 **没有能扫二维码的摄像头**，浏览器里也扫不了电脑屏幕上的码。所以：

**二维码只印「手机加入」。大屏地址用大号文字，让人在电视遥控器上打字。**

家里任选一种即可：

| 做法 | 怎么操作 | 什么时候用 |
|------|----------|------------|
| 电视浏览器输入地址 | 电脑管理页用超大字显示，例如 `http://192.168.1.8:8080/s`（`/s` 等于大屏页，少打几个字母）。电视打开浏览器，对着电脑敲进去，收藏一次下次不用打 | 电脑和电视分开摆，最常见 |
| 电脑接到电视 | HDMI 把电脑画面接到电视，在管理页点「本机当大屏」 | 客厅电脑本来就插着电视 |
| 对照手机打字 | 手机先加入，大厅里有「电视请打开下面这一串」，字很大，拿着手机到电视前对着敲 | 电脑屏幕离电视远，看不清管理页 |
| 主机装在电视上 | 以后的安装包，开机自己进大屏 | 第一版不做 |

路径尽量短：大屏用 `/s` 或 `/screen` 都可以。以后可以再做成 `http://game.local/s` 这类好记名字，第一版先用 IP。

不要指望：电视摄像头扫码、手机「隔空把网址推到电视」（每家电视品牌不一样，框架不依赖这个）。

---

## 主机怎么认出：这是电视，还是某个玩家

**不靠「看起来像电视」来猜。** 不根据手机型号、浏览器名称去判断。否则平板、电脑浏览器都会认错。

靠两件事：**打开的是哪个页面**，以及 **连上时报自己的身份**。

### 两套入口，从一开始就分开

| 谁 | 打开什么 | 连上之后主机怎么记 |
|----|----------|-------------------|
| 客厅电视（或电脑上点「本机当大屏」） | **大屏地址** `/screen` | 这是 **大屏**。不选家里谁的名字，也不占玩家名额 |
| 手机 / 平板 | **加入地址** `/`（手机二维码只印这个） | 先选或创建一个名字，这才是 **玩家** |

电脑上的主机窗口是 **管理界面**：大屏地址用超大号字体、手机加入用二维码、「本机当大屏」按钮。默认 **不要** 自动占用大屏身份——大屏留给电视浏览器。没有单独的电视时，再手动点「本机当大屏」。

### 连上的那一瞬间要登记

网页连到主机时带上一张「证件」：

- 大屏说：我是大屏。  
- 玩家说：我是玩家，我是「小明」（带上选名字时主机发给这个手机的凭证）。

没有选名字，就不能当玩家。没有走大屏页，就不能当电视。

可以同时开多块大屏。每块都收到同一份坐标，自己画。还有至少一块连着，游戏就仍然认为「有大屏」。最后一块离开，才通知游戏大屏没了。

### 开始游戏之后

身份已经登记过了，只换页面，不换身份：

- 每人一屏的游戏 → 玩家的手机打开游戏画面。  
- 电视+手柄的游戏 → 大屏打开游戏画面，玩家的手机改成手柄。还是同一个人，不是新连接冒充电视。

大厅里「谁在线」只列出选了名字的人。大屏单独显示「电视已连接」，不算作一个玩家。

### 不这么做的原因

- 用「是不是这台电脑自己打开的」判断：电视用浏览器去访问电脑时，并不是电脑本机，会认不成大屏。  
- 用「浏览器像不像电视」判断：很多电视浏览器会报成 Chrome，不可靠。

## 功能清单（实现时对照）

### 启动

- 打开后显示本机局域网地址、端口（默认 8080）。  
- 大屏地址用超大字体（供电视遥控器输入），并提供短路径 `/s`。  
- 加入地址用二维码（只给手机扫）。  
- 管理窗口留在电脑上；不自动把电脑当成大屏。提供按钮「本机当大屏」（电脑已接 HDMI 到电视时用）。
- 管理页提供 **游戏日志**：做游戏的人能看到各台设备打出来的 log 和页面报错，不用在电视上开开发者工具。家人平时可以不管。
- 管理页可以 **踢下线**：占用中的名字被放开，那台手机回到选人；档案还留着。
- 管理页卸载已装游戏前，要再确认一次。取消就留下。

### 大厅

- 显示谁在线、**自己现在是谁**（名字和颜色）、游戏列表、现在是空闲还是正在玩哪一款。  
- 游戏卡片上标明：每人一屏还是电视+手柄，以及能几个人玩。固定人数写成「2 人」「4 人」，一段范围写成「1～2 人」「1～4 人」。  
- 没有房间号、没有多桌。

### 开始 / 结束一局

- 大厅空闲时，已进来的成员可以点游戏开始。当前在线人数不在这款游戏声明的人数里时，开始按钮不可用，并写明现在几人、这款要几人。只算选了名字的人，不算大屏。  
- 电视+手柄类游戏：当时还没有大屏连上时，开始按钮不可用，提示「请先打开大屏」。  
- 人已经在玩时，后来的人如果还没满员，就加入当新的一手柄；满了就等这局结束。  
- 玩的时候不必回到大厅才能停：手机游戏页可以打开一个额外菜单，选「退出游戏」；电视+手柄时，手柄页也可以关这一局。电视画面本身不挡操作。  
- 结束后所有人回大厅。  
- 最后一块大屏关掉：主机只告诉还在的游戏「大屏没了」。还有别的大屏连着时不发这句。停不停由这款游戏自己决定，主机不替它暂停。

### 谁是电视、谁是玩家

- 大屏走 `/screen` 或 `/s`（电视手输）；加入走 `/`（手机扫码）。  
- 连接时必须声明身份：大屏，或「玩家 + 名字凭证」。  
- 大屏可以有多块，看到的是同一份画面；玩家必须先认领档案。  

### 传话

- 每个人的手机、以及电视，各自连着主机。  
- 手机手柄发出「按了什么」；主机转给正在算规则的那一端。  
- 算规则的那一端把「现在画面该长什么样」发给电视（需要时也给手机换按钮样子）。

### 游戏包里有什么

一款游戏是一个文件夹，至少有一份说明文件（名字、人数、属于哪种玩法）。按玩法还要提供对应页面：

- 每人一屏 → 手机上的游戏页  
- 电视+手柄 → 电视用的画面页 + 手机用的手柄页  
- 需要主机算规则 → 再加一份给主机运行的脚本（可选）

游戏不能自己在主机上装数据库、不能自己监听端口。存档必须走主机提供的接口。

## 开发技术（给写代码的人看）

产品形态上面已经说完。实现上选定：

| 用途 | 选择 |
|------|------|
| 主机程序 | TypeScript，用 **Bun** 跑，可打成单文件给家人 |
| 网页服务 | **Hono** |
| 手机/电视实时通信 | **WebSocket** |
| 人名和存档 | **SQLite**（做在主机程序里，不另装数据库软件） |
| 大厅和大屏外壳 | **Vite + Svelte 5** |
| 每人一屏、手柄界面 | TypeScript + Svelte 或普通网页 |
| 电视上的 2D 游戏 | **Phaser 3** |
| 需要主机算规则时 | TypeScript 打成一份脚本，由主机单独开一个工作线程加载 |

第三方做游戏：最终交出静态网页（加上面那份可选脚本），调用官方提供的连接方法即可。构建工具官方推荐 Vite。

仓库大致分成：主机、大厅、给游戏用的连接库、手柄控件、已安装的游戏目录、存档数据目录。

## 分步做

**第一步**：电脑上能开主机；电视浏览器进大屏、手机加人；能创建名字；大厅能选游戏；做一款「每人手机答题」；另做「手机按键、电视显示谁按了」打通手柄通道。

**第二步**：游戏按文件夹安装；能从游戏源下载；做出一款正式的「大屏画面 + 手机手柄」小游戏（规则先在点开始的那位玩家的页面里算）。

**第三步**：支持「规则在主机里算」（已做）；手柄短时间掉线能重连；尝试电视/安卓上的安装包。

**更后**：电视上看公共画面、手机上看私密信息；备份存档；用局域网名字访问而不记 IP。

---

## 怎样算做对了

1. 两部手机用两个名字进入同一个大厅，不用输房间号。  
2. 答题类游戏能分清谁是谁；关掉主机再开，存过的分数还在。  
3. 电视（或电脑大窗口）上是完整游戏，两部手机只有手柄，按键结果出现在大屏。  
4. 新游戏拷进去或从游戏源下下来，大厅里能出现并能开玩。  
5. 下载包被改过则安装失败。主机断外网，已装的游戏还能玩。  
6. 某款游戏的主机脚本出错，只结束这一局，主机还能继续用。

---

## 明确不做

- 互联网联机、云存档、登录注册  
- 房间号、家里同时开两桌  
- 收费商店、官方审游戏  
- 让游戏脚本在电脑上为所欲为  

---

## 已经定下来的事

- 家庭 Wi‑Fi，用浏览器玩  
- **默认：主机装在电脑上；电视、手机分别用浏览器访问**  
- 像马里奥派对：一个大厅，一款一款玩  
- 人的名字和游戏进度存在主机上  
- 支持「每人一屏」和「电视大屏 + 手机手柄」  
- 需要时，规则可以在主机里算  
- 可以从别人的游戏源下载游戏  
- 开发技术按上一章选定

## 你还没说、我先按这个做的

不反对的话就按括号里的做。

1. 先做的示例：手机答题 + 一个大屏按键小游戏  
2. 中途进来：人没满就当新手柄加入  
3. 同名被两台手机点：先点到的人占住，后来的不能再选；选人页要马上看出谁已经被选走  
4. 名字不要密码  
5. 头像先用名字 + 颜色  
6. 界面先做中文  
7. 谁都可以在大厅点开始  
8. 又开了一个大屏：用新的，换掉旧的  
9. 下载包没有校验码：不安装  
10. 「电视公共画面 + 手机私密信息」：以后再做

## 用词对照

怕以后文档里中英文混着看晕，固定这几个词：

| 说法 | 指什么 |
|------|--------|
| 主机 | 默认跑在家里电脑上的服务程序 |
| 大厅 | 选人、等人、选游戏的界面 |
| 档案 / 名字 | 家里每个人在主机里的身份 |
| 大屏 | 电视或电脑上只负责给大家看的那块画面 |
| 手柄 | 手机上只负责操作的界面 |
| 游戏源 | 一份网上的游戏目录，主机可以去那里下载 |
| 主机运算 | 这款游戏把规则放在主机里跑，而不是放在网页里跑 |
